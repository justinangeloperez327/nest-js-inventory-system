# NestJS Inventory System

Inventory management API built with NestJS and TypeScript.

## Requirements

- Node.js 24 LTS or newer
- npm 11 or newer

## Setup

```bash
npm install
npm run start:dev
```

The application starts on `http://localhost:3000` by default.

## Scripts

```bash
npm run build
npm run start
npm run start:dev
npm run lint
npm run format
npm run test
npm run test:e2e
```

## Stack

- NestJS 12
- TypeScript
- Express
- Vitest
- OXLint
- Prettier
